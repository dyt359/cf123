基础自定义

用于指定回退地址或 ProxyIP，格式 IP:端口。留空时使用内置地址池。

ECH 与高级网络

加密客户端问候，开启后会强制仅走 TLS 节点。
用于 ECH 配置查询，格式：https://223.5.5.5/dns-query。需为支持 DoH 的地址。
默认为 cloudflare-ech.com。用于 ECH 加密握手的域名，影响 CDN 资源可达性。

控制开关

关闭优选后只用原生地址，不再使用优选 IP 列表。
关闭后不进行地区智能匹配，直接使用默认节点。
控制代理与直连的回落逻辑：「只走代理」时代理失败会直接报错而非回落。
开启后只生成带TLS的节点。启用 ECH 时该项会被强制为「仅TLS节点」。

延迟测试与优选管理

在浏览器中直接向目标节点发起请求测速（8 秒超时），结果可覆盖或追加到优选列表。

每行一个地址，支持 IP 或域名。可直接粘贴从优选IP来源URL获取的列表。
默认 443。需与节点实际服务端口一致，否则测速结果不具参考性。

地址 延迟
「覆盖」会清空原优选列表后写入本次测试成功的地址；「追加」只新增，不删除已有条目。
